# Agentic Banking CRM Frontend

Single-page React + Vite + Tailwind dashboard for the `POST /analyze` API.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

## API base URL

By default the app calls `http://127.0.0.1:8000/analyze`.

To change it, set:

```bash
VITE_API_BASE_URL=http://127.0.0.1:8000
```
